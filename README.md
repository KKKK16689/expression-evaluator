# 表达式求值器 · 栈的应用

《算法与数据结构》实验三「线性结构综合应用」配套的可视化演示页面。

**在线体验**：https://kkkk16689.github.io/expression-evaluator/

单文件 HTML，零依赖，双击即可运行；也可直接扫上面的链接在手机上打开。

## 它做了什么

页面左侧是按实验要求实现的计算器（仅支持 `+ − × ÷`、正整数、圆括号），右侧把算法执行过程完整摊开：

- **中缀 → 后缀**：逐字符扫描，每一步说明 `Precede(op1, op2)` 的比较结果
- **双栈可视化**：运算符栈 `SqStackChar` 与数值栈 `SqStackDouble`，实时显示入栈、出栈、栈顶
- **单步回放**：可前进、后退、自动播放，共 24 步走完 `(3+4)×5-6÷2`
- **异常处理**：`5÷(3-3)` 除数为 0 时给出提示并终止，不输出 inf

## 算法

与实验报告的实现严格一致：

1. `trans()`：运算符栈压入 `=` 作栈底哨兵，按 7×7 优先级表决定出栈还是压栈；数字串拼接后以 `#` 结尾输出
2. `compvalue()`：扫描后缀表达式，遇数字压栈，遇运算符弹出两个操作数（先弹出的是右操作数）计算后压回；除法前检查除数是否为 0

两个阶段都是单趟扫描，时间复杂度 O(n)，空间复杂度 O(n)。

## 自检

```bash
node test.js
```

直接从 `index.html` 里抽取算法代码执行，验证的就是页面实际运行的那一份，13 组用例：

| 输入 | 后缀 | 结果 |
|---|---|---|
| `3+4*5` | `3#4#5#*+` | 23 |
| `(3+4)*5-6/2` | `3#4#+5#*6#2#/-` | 32 |
| `((2+3)*4)` | `2#3#+4#*` | 20 |
| `7/2` | `7#2#/` | 3.5 |
| `5/(3-3)` | `5#3#3#-/` | 除数为 0，终止 |
| `123` | `123#` | 123 |
| `8-4-2` | `8#4#-2#-` | 2 |
| 其余 6 组（综合、嵌套、负数结果、非法表达式等） | — | 全部通过 |

## 快捷入口

地址后加 `#表达式` 可直接打开某个用例，加 `@步骤` 定位到某一步，例如：

```
https://kkkk16689.github.io/expression-evaluator/#(3+4)*5-6/2@12
```
